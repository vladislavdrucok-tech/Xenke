# Перевірки POST 404 (стан на 0.1.0)

## Автоматичні (headless) — `tests/run_tests.gd`
Запуск: `godot --headless --path post-404 -s res://tests/run_tests.gd` → **246 passed, 0 failed**.

- Правила: напрямки, дзеркало, календар, шаблони з «?».
- Чесність генератора: ~105 000 посилок на рівнях 1–60, з усіма маршрутами, при зсуві календаря й дзеркалі —
  кожна має рівно одну відповідь, яку можна вивести з видимого.
- Поступове відкриття: на 1-му рівні немає «теперішнього» й особливих посилок; на 12-му є всі типи; особливих — меншість.
- Без довгих серій однакових відповідей (максимум 4 поспіль).
- Сесії: ідеальний гравець — 3 зірки; випадковий — програє раніше часу; рекорд закінчується; бездіяльність у рекорді
  — 3 помилки за таймером; спокійний режим не закінчується сам і не знімає надійність; навчання — 8 заданих посилок.
- Події: усі 5 трапляються, посилки лишаються чесними під час зміни правил, правила відновлюються.
- БІТ: допомагає із забутою посилкою без серії; щит серії спрацьовує один раз.
- Покупки й економіка: ціни, максимальні рівні, вимоги рівня/кімнат/уламків, офлайн-дохід із лімітом 8 год,
  щоденна нагорода лише раз.
- Баланс (симуляція гравця з точністю 93%, ~1,1 с на посилку): перша покупка після 1–2 змін, 12-й рівень (фінал
  сюжету) приблизно на 25-й зміні, усе куплено лише після ~250 змін.
- Збереження: запис/читання, міграція v1, очищення поганих значень, пошкоджений файл → резервна копія, обидва
  пошкоджені → нова гра.
- Сюжет: порядок глав, вимоги, нагороди, таємна кінцівка закрита без потрібних виборів.
- Локалізація: кожен рядок має uk і en; є тексти для всіх відкриттів і підказок.

## Візуальні — `tests/screenshot_tour.gd`
`xvfb-run godot --path post-404 --resolution 720x1280 -- --save=user://tour.json --shots=/tmp/shots`
проходить пролог, навчання (справжні свайпи через ту саму функцію, що й кнопки), меню, зміну, усі особливі
посилки, підказки, дзеркало, календар, паузу, результати, відділення, колекцію, листи, глави, вибір у сюжеті,
рекорд. Перевірено на 720×1280 (16:9), 720×1600 (20:9) і 960×1280 (планшет): елементи не виходять за межі,
скриптових помилок немає.

## Збірка
`--export-debug "Android"` → APK підписано (v1/v2/v3, zipalign перевірено), ~50 МБ (дві архітектури).

## Що НЕ перевірено
- Запуск на фізичному Android-телефоні та реальна частота кадрів (емулятора в середовищі немає).
- Звук на слух (у контейнері немає аудіопристрою; файли згенеровано й перевірено формат/цикл).
- Вирізи екрана: код читає `DisplayServer.get_display_safe_area()`, але на пристрої з вирізом не перевірявся.
- iOS-збірка (потрібні macOS і Xcode).
