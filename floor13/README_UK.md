# FLOOR 13: NIGHT SHIFT

Проста весела 2D-гра в піксельному стилі для Android (вертикально, одним пальцем, без інтернету).
Ти — нічний ліфтер у дивному готелі. Гості з'являються на поверхах і показують, куди їм треба; довозь їх, заробляй монети й покращуй ліфт.

**Встановити:** `builds/Floor13-NightShift-0.5-universal.apk` (працює на всіх Android-телефонах; на GitHub: відкрити файл → «Download raw»; на телефоні дозволити встановлення з цього джерела).

**Як грати:**
- Натисни кнопку поверху внизу — ліфт поїде туди. Кнопка світиться, поки зупинка в планах; натисни ще раз, щоб скасувати.
- Число в бульбашці над гостем — його поверх. Колір бульбашки — терпіння.
- Кружечок зліва на кнопці — скільки гостей чекає на тому поверсі, блакитний справа — скільки пасажирів їде туди.
- Можна також торкнутися самого поверху в будівлі; прокручуй будівлю пальцем.
- Не дочекався гість — скарга. Усі серця втрачено — зміну провалено (монети лишаються).

**Відкрити в редакторі:** Godot 4.3 → Import → `floor13/project.godot`.
