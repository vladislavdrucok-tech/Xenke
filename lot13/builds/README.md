# LOT 13 — APK для телефона

`LOT13-Lucky-Garage.apk` збирає GitHub Actions (`.github/workflows/lot13.yml`) і кладе сюди,
коли коміт містить `[apk]` або прогін запущено вручну (Actions → LOT 13 build → Run workflow).

Як поставити: відкрити файл на GitHub → «Download raw» (або «⋯ → Download») → відкрити APK на Android
і дозволити встановлення з цього джерела. Підпис — тестовий ключ `lot13/tools/debug.keystore`,
тож нові збірки ставляться поверх старих без видалення гри (прогрес зберігається).
