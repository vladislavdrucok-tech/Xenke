# FLOOR 13: NIGHT SHIFT — журнал розробки й інструкція для продовження

Окремий проєкт Godot 4.3 у папці `floor13/`. Інші папки репозиторію (Afterfall, `godot/`, `iso/`, `squad/` тощо) він не використовує й не змінює.

## Стан на зараз (v0.5)

Готова гра, яку можна встановити на Android: `builds/Floor13-NightShift-0.5.apk` (arm64, вертикальна орієнтація, без інтернету).

Що є в грі:
- **Один ігровий екран**: розріз готелю (шахта ліфта, поверхи, дах із неоном, вулиця з таксі), панель із 13 кнопками поверхів унизу, HUD зверху.
- **Поверхи**: старт із 5, кожна успішна зміна відкриває наступний, до 13. Кожен поверх має свою тему (хол, ресторан, номери, басейн, бібліотека, спортзал, оранжерея, диско, спа, казино, обсерваторія, пентхаус, «???»).
- **Ліфт**: плавний рух із прискоренням і гальмуванням; зупиняється на натиснутих поверхах по дорозі; повторне натискання скасовує зупинку; розсувні ґратчасті двері.
- **11 типів пасажирів** (поступово): турист, бізнесмен, бабуся (з першої зміни); дитина (натискає зайву кнопку), кіт (без місця), рок-зірка (дратує сусідів, платить щедро), робот-кур'єр (бонус без зупинок), молодята (2 місця), інспектор (VIP: прощає скаргу або дає дві), носій із валізами (3 місця), привид (лише 13-й поверх).
- **Терпіння**: колір бульбашки (зелений/жовтий/червоний) і смужка. Гість, що не дочекався, пише скаргу (серце). У кабіні гість не скаржиться, але коли терпіння закінчується, сам натискає свій поверх і не дає чайових.
- **11 випадкових подій** (з 2-ї зміни, по одній): джазова пауза, щедра ніч, вечірка на поверсі, турбо-мотор, розсипані монети, навчальна тривога, липкі двері, аварійне світло, привид-жартівник (натискає кнопку — можна скасувати), загублений кіт, інспектор.
- **10 правил ночі** (з 3-ї зміни, одне на ніч, показується на картці перед зміною).
- **Економіка**: тариф за відстань × тип пасажира × чайові за терпіння × серія (до ×1,5) × події/правила.
- **7 покращень** у магазині: мотор, кабіна, двері, кава в холах, джаз у кабіні, уніформа (чайові), книга скарг (+серця).
- **Нескінченні зміни**: тривалість, частота гостей і нетерплячість зростають; ліміти черг не дають створити неможливу ситуацію.
- **Рекорди** й галерея зустрінутих гостей; **навчання** (інтерактивне, можна пропустити й пройти знову); **автозбереження** (JSON у `user://`, запис із затримкою 1 с і примусово при згортанні застосунку); налаштування звуку, музики, вібрації, скидання прогресу.
- **Керування одним пальцем**: кнопки панелі (реагують на дотик, не на відпускання), дотик до поверху в будівлі, прокрутка будівлі пальцем. Кнопка «Назад» Android: пауза / назад / вихід із меню.
- **Персонажі (v0.5)**: спрайти 32×32, по 18 кадрів на тип — спокій (дихання, кліпання), ходьба (6 кадрів), власна дія в очікуванні (турист фотографує, бізнесмен дивиться на годинник, бабуся в'яже, дитина стрибає, кіт вилизується, рокер грає на повітряній гітарі, робот «думає», молодята цілуються, інспектор пише, носій витирає піт, привид лякає), гнів, радісний стрибок; кольоровий контур, тіні на підлозі. Розкладка кадрів і висота кожного типу — у `assets/sprites/passengers.json`.
- **Характери**: кожен тип має свої короткі репліки (вітання, подяка, обурення) у бульбашках; монети летять до лічильника.
- **Завдання ночі**: на кожну зміну одна необов'язкова мета (довезти N гостей, серія, монети, певний тип гостей, доставки без зупинок, зміна без скарг) з нагородою; прогрес видно під HUD.
- **Довгострокові цілі**: 5 оздоблень кабіни (класика, неон, ретро-м'ята, золото, «привидна» після 13-го поверху) і 14 досягнень із нагородами монетами (показуються спливаючою табличкою й у «Рекордах»).
- **Звук**: 37 синтезованих ефектів (дзвінок ліфта, двері, монети, «голоси» кожного типу, гул мотора), дві джазові музичні петлі (меню і зміна).

## Структура

| Шлях | Що це |
|---|---|
| `project.godot` | 360×640 базова роздільність, `canvas_items` + цілочисельне масштабування, портрет |
| `scripts/defs.gd` | усі дані: типи пасажирів, покращення, події, правила, макет |
| `scripts/sim.gd` | `ShiftSim` — правила зміни без графіки (ліфт, пасажири, спавн, події, монети), + автопілот `bot_step()` |
| `scripts/world_view.gd` | малювання готелю, пасажирів, бульбашок, ефектів; камера й прокрутка |
| `scripts/floor_panel.gd` | панель кнопок поверхів з індикаторами |
| `scripts/hud.gd` | верхня панель і банер подій |
| `scripts/game.gd` | екран зміни: цикл, звуки, картки «перед зміною», «пауза», «результати» |
| `scripts/tutorial.gd` | інтерактивне навчання |
| `scripts/menu.gd`, `shop.gd`, `info_screen.gd` | меню (з живим готелем на фоні), покращення, рекорди/налаштування |
| `scripts/save.gd`, `sfx.gd`, `art.gd` | автозбереження, звук, спільні текстури/шрифти/кнопки |
| `tools/make_art.py` (+`art_*.py`) | генерує ВСЮ піксельну графіку в `assets/sprites`; пасажири — `tools/art_people.py` (пози, ходьба, дії кожного типу) |
| `tools/make_sfx.py` | синтезує звуки (`assets/sfx`) і музику (`assets/music`) |
| `tools/build_apk.sh` | тести + збірка підписаного APK |
| `tools/check_export.sh` | експорт паку й прогін гри поза редактором (ловить помилки експорту) |
| `tests/run_tests.gd` | логічні тести + бот-кампанія для балансу |
| `tests/scenes.gd` | `--scene=<папка>`: постановочна сцена для скриншотів; `--soak=N`: N повних змін через справжні екрани на швидкості ×8 |

## Команди

```sh
G=/home/user/tools/godot/Godot_v4.3-stable_linux.x86_64
$G --headless --editor --quit --path floor13                      # імпорт ресурсів
$G --headless --path floor13 -s res://tests/run_tests.gd           # тести
$G --headless --path floor13 -s res://tests/run_tests.gd -- --campaign --shifts 20 --seed 7   # баланс
xvfb-run -a $G --path floor13 --rendering-driver opengl3 --resolution 360x780 -- --shots=/tmp/shots  # скриншоти всіх екранів
xvfb-run -a $G --path floor13 --rendering-driver opengl3 --resolution 360x780 -- --soak=14    # довгий прогін без помилок
python3 floor13/tools/make_art.py && python3 floor13/tools/make_sfx.py   # перегенерувати графіку/звук
floor13/tools/check_export.sh && floor13/tools/build_apk.sh
```

## Як зібрати APK у новій сесії (середовище щоразу нове)

1. Godot 4.3 і шаблони експорту (GitHub-релізи доступні):
   - `https://github.com/godotengine/godot/releases/download/4.3-stable/Godot_v4.3-stable_linux.x86_64.zip` → `/home/user/tools/godot/`
   - `.../Godot_v4.3-stable_export_templates.tpz` → розпакувати `templates/*` у `~/.local/share/godot/export_templates/4.3.stable/`
2. Android SDK з `dl.google.com` недоступний, тому: `apt-get install -y apksigner adb zipalign` і фальшива структура SDK:
   ```sh
   SDK=/home/user/tools/android-sdk; mkdir -p $SDK/platform-tools $SDK/build-tools/34.0.0
   ln -sf /usr/bin/adb $SDK/platform-tools/adb
   ln -sf /usr/bin/apksigner $SDK/build-tools/34.0.0/apksigner
   ln -sf /usr/bin/zipalign $SDK/build-tools/34.0.0/zipalign
   ```
   Запустити редактор раз (`--headless --editor --quit`), потім у `~/.config/godot/editor_settings-4.3.tres` задати `export/android/android_sdk_path = "/home/user/tools/android-sdk"`.
3. Ключ підпису: `keytool -genkeypair -keystore /home/user/tools/keys/floor13.keystore -alias floor13 ...` і передати шлях/псевдонім/пароль змінними `KEYSTORE`, `KEY_ALIAS`, `KEY_PASS` у `tools/build_apk.sh`.
   **Увага:** ключ не зберігається в репозиторії. Новий ключ = інший підпис, тож нову збірку не можна встановити поверх старої — спершу видалити стару (прогрес на телефоні при цьому зітреться). Щоб оновлення ставали поверх, потрібен один постійний ключ, який власник зберігає сам.
4. Для старих 32-бітних телефонів увімкнути `architectures/armeabi-v7a=true` у `export_presets.cfg` (APK стане ~46 МБ замість ~25 МБ).

## Баланс (бот-кампанія, жадібні покупки)

Бот натискає всі потрібні кнопки з реакцією 0,6 с. Він проходить зміни 1–9 з поодинокими повторами, «стіна» — приблизно зміни 13–17 з усіма покращеннями. Параметри складності — `ShiftSim.patience_scale()`, `spawn_interval()`, `max_waiting()`, тривалість — `Defs.shift_duration()`.

## Журнал

- **v0.5** — персонажі перебудовані: більші спрайти, 18 кадрів анімації на тип, своя дія в очікуванні, тіні; табло призначень над кабіною замість ярликів у ній.
- **v0.4** — безпечна зона екрана: HUD і кнопки не ховаються під виріз камери чи жестову панель (`Art.safe_insets()`; для перевірки на ПК — змінна `F13_INSETS=28,18`).
- **v0.3** — завдання ночі; камера показує новий поверх, коли він відкривається (пил і напис); адаптивна іконка Android (окремий передній план і небо), чіткі цифри «13» на іконці.
- **v0.2** — репліки пасажирів, політ монет, оздоблення кабіни, досягнення; виправлено: подвійні рядки на картці 1-ї зміни, застрягання навчання, банер подій не влазив, вказівник навчання, 3 зірки без доставок; черга відсунута від таблички поверху; невелика будівля «стоїть» на землі. Прогін 14 змін через справжні екрани — без помилок.
- **v0.1** — повна гра: прототип логіки з тестами → піксельна графіка й звук генераторами → екран зміни, меню, магазин, рекорди, налаштування, навчання → підписаний APK.
