## Наступні кроки (за пріоритетом)
1. **Рішення власника:**
   - затвердити `docs/ART_SPEC.md` (128×64, палітра);
   - назвати цільовий Android-пристрій;
   - дати дозвіл на тег-знімок Afterfall.
2. **ChatGPT:** тікети C1 (Енцо), B1 (майстерня), G1 (земля), V1 («Монарх»). Під них:
   - імпортер і валідатор (`tools/validate_assets`);
   - заміна заглушок для героя, майстерні, землі й машини.
3. **Експорт:** пресети Windows/Android (`ua.chicago.bloodloyalty`), встановлення шаблонів 4.3, тестовий APK, тест на телефоні (кадри, мультитач, згортання).
4. **Трафік:** граф смуг із даних району, 2–3 машини NPC, зупинка перед героєм.
5. **Погоня:** поліцейська машина переслідує авто героя; зіткнення збільшують розшук.
6. **Налаштування:**
   - масштаб інтерфейсу;
   - автоприціл увімк./вимк.;
   - перепризначення клавіш (`user://input.cfg`);
   - гучність (коли з'явиться звук).
7. **Нелінійний вибір у беаті 3:** якщо Енцо відмовився, Марко повертається ввечері з іншою пропозицією; на це впливає стосунок.
8. **CI:** GitHub Actions з Godot 4.3 без вікна, запуск `tools/run_tests.sh`.
