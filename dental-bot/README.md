# AI-адміністратор для стоматологій — MVP

Бот для сайту і Telegram приватної клініки. Він відповідає пацієнтам за прайсом і текстами з сайту саме цієї клініки, записує ім'я й телефон і одразу надсилає заявку адміністратору в Telegram.

У комплекті все для продажу: генератор демо за адресою сайту, презентація на 5 слайдів з даними клініки, кабінет із заявками й діалогами і набір для продажу в папці [`sales/`](sales/README.md).

```
сайт клініки ──► обхід 25 сторінок ──► база знань (ціни, телефони, адреса, графік, послуги)
                                              │
пацієнт ──► віджет на сайті / Telegram ──► Claude ──► відповідь
                                              └──► save_lead ──► Telegram адміністратора + кабінет
```

## Швидкий старт (5 хвилин)

Потрібен Node.js 18.17+.

```bash
cd dental-bot
npm install
cp config.example.json config.json      # впишіть своє ім'я, телефон, ціни пропозиції
export ANTHROPIC_API_KEY=sk-ant-...     # без ключа бот працює в простому локальному режимі
npm run sample                          # демо на вигаданому сайті «ДемоДент», без інтернету
```

У консолі з'являться посилання на демо, презентацію й кабінет. Пароль кабінету теж виводиться в консоль, або задайте свій через `ADMIN_PASSWORD`.

## Демо для справжньої клініки

```bash
node scripts/new-demo.mjs https://сайт-клініки.ua --name "Стоматологія «Назва»"
npm start
```

- Відкрийте `http://localhost:8787/demo/<slug>`. На скріншоті сайту клініки вже відкритий чат.
- Задайте 5–10 питань, які ставлять пацієнти, і перевірте відповіді. Тільки після цього надсилайте посилання.
- Презентація — `http://localhost:8787/pitch/<slug>`. Гортається стрілками, у PDF зберігається через Ctrl+P → «Зберегти як PDF», альбомна орієнтація.

Корисні опції:

| Опція | Що робить |
|---|---|
| `--name "…"` | Назва клініки, якщо із сайту визначилась довга або невдала. |
| `--max-pages 40` | Обійти більше сторінок (за замовчуванням 25). |
| `--no-screenshot` | Без скріншота; у демо буде макет із даними клініки. Скріншот потребує `npm i playwright && npx playwright install chromium`. |
| `--no-sample` | Не генерувати приклад діалогу для 2-го слайда (3 запити до AI). |

Демо для цілого списку клінік:

```bash
node scripts/batch-demos.mjs sales/prospects.csv --max 15
```

Скрипт дописує в CSV колонки `demo_url` і `pitch_url`.

Те саме можна робити з кабінету: вкладка «+ Нове демо».

## Публічна адреса: щоб клініка відкрила посилання

Посилання `localhost` працюють лише на вашому комп'ютері. Є два шляхи.

**1. Найшвидше, для дня продажів.** Тунель Cloudflare, без реєстрації:

```bash
cloudflared tunnel --url http://localhost:8787     # видасть https://….trycloudflare.com
PUBLIC_URL=https://….trycloudflare.com npm start
```

Поки ноутбук увімкнений, посилання працюють. Встановлення `cloudflared`: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

**2. Для клієнтів, що заплатили.** VPS за €4–6/міс (Hetzner, DigitalOcean) із доменом.

```bash
docker build -t dental-bot .
docker run -d --restart=always -p 8787:8787 -v /srv/dental-data:/data \
  -v $(pwd)/config.json:/app/config.json:ro \
  -e ANTHROPIC_API_KEY=... -e ADMIN_PASSWORD=... -e PUBLIC_URL=https://bot.вашдомен.ua \
  -e TELEGRAM_BOT_TOKEN=... dental-bot
```

HTTPS забезпечить Caddy (`caddy reverse-proxy --from bot.вашдомен.ua --to :8787`) або Cloudflare.

## Підключення клієнта

1. **Віджет на сайті.** Скопіюйте код у кабінеті: «Клініки й демо» → «Код для сайту клініки». Клініка (або її розробник) вставляє один рядок перед `</body>`:
   ```html
   <script src="https://bot.вашдомен.ua/widget.js" data-clinic="slug" defer></script>
   ```
   Для WordPress підійде плагін на кшталт «Insert Headers and Footers».
2. **Заявки в Telegram.**
   - Створіть бота в @BotFather і запустіть сервер із `TELEGRAM_BOT_TOKEN=...`.
   - Адміністратор пише боту `/id`, бот відповідає chat id.
   - Впишіть цей chat id у кабінеті: «Налаштування» клініки → поле «Telegram chat id».
   - Можна групу: додайте бота в групу, напишіть там `/id`.
3. **Telegram-бот для пацієнтів (необов'язково).** Той самий бот відповідає пацієнтам, якщо вказати, для якої клініки він працює: `TELEGRAM_BOT_CLINIC=slug`. Один процес — один такий бот. Для кількох клінік запустіть кілька процесів з різними токенами (порт і `DATA_DIR` у них можуть бути спільні).
4. **Оновлення цін.** Коли клініка змінює прайс, ще раз виконайте `node scripts/new-demo.mjs <сайт>`. База знань оновиться, а налаштування збережуться.

## Налаштування

`config.json` (зразок — `config.example.json`) і змінні середовища:

| Змінна | Призначення |
|---|---|
| `ANTHROPIC_API_KEY` | Ключ Claude API: https://console.anthropic.com. Без нього працює локальний режим (пошук по сайту за ключовими словами, без AI). |
| `CLAUDE_MODEL` | Модель, за замовчуванням `claude-opus-5-5`. Дешевший варіант: `claude-haiku-5-5`. Перед зміною моделі перевірте якість відповідей на своїх питаннях. |
| `CLAUDE_EFFORT` | `low` (за замовчуванням) — швидкі короткі відповіді. `medium` — ретельніше, повільніше. |
| `ADMIN_PASSWORD` | Пароль кабінету `/admin` (логін будь-який). |
| `PUBLIC_URL` | Публічна адреса для посилань у демо, презентації та коді віджета. |
| `PORT`, `DATA_DIR` | Порт (8787) і папка з даними (`./data`). |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_CHAT_ID`, `TELEGRAM_BOT_CLINIC` | Telegram: токен, chat id за замовчуванням, клініка для бота пацієнтів. |
| `AI_MODE=off` | Примусово локальний режим. |

Ліміти від зловживань (у `config.json` → `limits`):
- 60 повідомлень на діалог;
- 30 повідомлень з однієї IP за 10 хвилин;
- 2000 AI-відповідей на день (`ai.dailyMessageCap`). Після цього бот переходить у локальний режим, щоб рахунок за API не виріс несподівано.

## Як влаштований бот

- **База знань.** `src/crawl.mjs` і `src/extract.mjs` обходять сайт.
  - Спершу сторінки з цінами, послугами й контактами, потім решта.
  - Пропускаються `/ru/` і `/en/` дублікати, файли, адмінки й усе, що забороняє robots.txt.
  - Ціни беруться з таблиць і рядків із «грн/$/€».
  - Телефони, адреси й графік беруться з тексту, посилань `tel:` і розмітки schema.org.
  - Меню й футер, що повторюються на всіх сторінках, зберігаються один раз.
- **Відповіді.** `src/assistant.mjs`.
  - Системний промпт: правила поведінки плюс база знань клініки. Він стабільний між запитами і кешується на годину (prompt caching), тож повторні питання коштують у кілька разів дешевше.
  - Поточний час у Києві додається окремим службовим повідомленням, щоб бот знав, чи клініка зараз працює.
  - Заявку бот зберігає сам, інструментом `save_lead`. Телефон перевіряється на сервері; якщо номер несправжній, бот перепитує.
  - Історія діалогу лише дописується: цього вимагають кеш і thinking-блоки моделі.
  - Увімкнено серверний fallback (`fallbacks: "default"`): якщо модель відмовляє відповідати, API сам повторює запит на іншій моделі. Якщо відмовляють усі, бот передає розмову адміністратору й називає телефон клініки.
  - Якщо API недоступний, бот на цей хід відповідає в локальному режимі.
- **Правила бота** (промпт у `buildSystemPrompt`):
  - не вигадує цін і лікарів;
  - ціни подає як орієнтир;
  - не ставить діагнозів;
  - при гострому болю радить дзвонити, при загрозливому стані — 103;
  - відповідає мовою пацієнта;
  - чесно каже, що він віртуальний помічник.

### Скільки коштує AI

На тестах із заглушкою ціни не перевірити, тому дивіться реальні витрати в кабінеті: «витрати AI (оцінка)», а також по кожному діалогу. Порядок величин для Opus 5.5:
- базу знань на ~10–40 тис. токенів більшість запитів читає з кешу ($0.20 за 1M);
- типова відповідь — кілька сотих долара;
- 1000 повідомлень на місяць — десятки доларів, а не сотні.

Перевірте на перших реальних діалогах і закладіть у супровід із запасом.

```bash
npm test
```

12 тестів без мережі:
- обхід вигаданого сайту, robots.txt, витягування цін і телефонів;
- локальний режим через HTTP;
- AI-режим із заглушкою Claude API: формат запиту, кеш, інструмент заявки, відмова, збій API, лише дописування історії;

## Обмеження MVP — скажіть про них чесно

- **Сайти, що малюються JavaScript-ом** (Tilda буває, деякі SPA): обхід бачить мало тексту. Генератор попередить «Обійдено лише N сторінок». Тоді додайте ціни вручну або оберіть іншу клініку.
- **Дані — JSON-файли.** Для десятків клінік цього достатньо. Для сотень потрібна база даних.
- **Запис без розкладу.** Бот збирає заявку, а час підтверджує адміністратор. Інтеграція з CRM клініки — наступний етап (окрема плата).
- **Персональні дані.** Ім'я й телефон пацієнта — персональні дані.
  - У договорі з клінікою зазначте, що клініка — володілець даних, а ви — розпорядник.
  - Зберігайте дані лише на своєму сервері, з паролем на кабінет.
  - Не збирайте медичних подробиць понад потрібне для дзвінка.
- **Відповідальність за відповіді.** Перед запуском клініка має переглянути відповіді на типові питання. Кабінет показує всі діалоги.
