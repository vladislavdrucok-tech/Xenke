# Afterfall у Godot 4.3

**Головна сцена — місія 2.2 «Пральня на затопленій вулиці»** (`laundry.tscn`), зібрана з пакета графіки «Remaining» (`art/rest`).
Пробна сцена майстерні Міри (`main.tscn`) лишилась у проєкті для порівняння.

## Місія 2.2 «Пральня»
Шість етапів за `docs/STORY_MISSIONS_UK.md`:
1. **Підхід.** Вулиця затоплена (течія повертає на сухе, −10 здоров'я) → гак у брухті → стягнути пожежну драбину →
   балкони: опустити аварійний місток (A206), з ящика на дах, стрибок на останній балкон → двір → за стукотом до бічних дверей.
2. **Розвідка.** Вентиль на настилі спершу лише «оглянути»: герой називає, чого бракує, і мета стає списком —
   водостік у дворі, обвідна труба (хомут із ящика + ганчірка з сушарки), генератор для помпи.
3. **Осушення.** Голос із вентиляційної решітки: розмова з Назаром → опора-домкрат → завал → двері.
4. **Шлях.** Верхній настил: пролом (2 дошки) і струмінь з труби кожні 3,4 с (краплі попереджають).
   Машинний зал: три кроулери — консерва, бійка або барабан пральної машини (кроулери біжать на гуркіт і ~10 с не помічають героя).
5. **Доставка.** Ремені з шафи → корпус на візок і закріпити → ворот воріт → Назар штовхає; візок стоїть перед уламками й кроулером.
6. **Повернення.** Станція (A174) і майстерня (A116): Яна, зняти корпус з візка, поставити на верстак Міри.

Контрольні точки: вхід, порятунок, вибір шляху, ворота, Станція. Прапорці, речі й журнал зберігаються після кожної дії
(`user://afterfall_save.json`); після смерті — повернення на останню точку з повним здоров'ям, видані речі не дублюються.

## Нова графіка (блоки M, P, I, C — `docs/GPT_MISSING_ART_UK.md`)
1. Архіви розпакувати: `python3 godot/tools/import_new.py --unzip Afterfall_M1_Crawler.zip ...` → `art/new/<архів>/`.
2. `python3 godot/tools/import_new.py` — ріже все знайдене в `godot/assets/new/` і пише `godot/data/new_art.json`;
   `--status` лише показує, яких файлів ще бракує. Скрипт друкує перевірки: масштаб нових рухів відносно базового аркуша, ширину дверного отвору фасаду.
3. `godot --headless --import --path godot`, потім автопрохід і скриншоти.

Поки файлу немає, гра малює те, що й раніше (`scripts/art.gd` повертає «нічого»). Куди що піде:

## Пробна сцена (майстерня)
Майстерня Міри на Станції: верстак → ремонтний вузол → ремонт фільтра → кран → чиста вода. Щоб запустити її, відкрий `main.tscn` і натисни F6.

## Як відкрити
1. Завантаж Godot 4.3 (стандартний, не .NET): https://godotengine.org/download/archive/4.3-stable/
2. Godot → «Import» → вибери файл `godot/project.godot` → «Import & Edit».
3. F5 — запуск. Керування: A/D або ←/→, пробіл — стрибок, E — дія. Мишею можна натискати екранні кнопки.

## Автоперевірка (без редактора)
`godot --path godot --rendering-driver opengl3 -- --demo=<папка>` проходить сцену сам, зберігає скриншоти й друкує час кадрів; з `--perf` — лише заміри.

## APK для Android
Пресет «Android» у `export_presets.cfg` (без Gradle, лише arm64-v8a, альбомна орієнтація).
Потрібні: шаблони експорту 4.3, Java 17+, Android SDK з `platform-tools/adb` та `build-tools/<версія>/apksigner`
(шляхи — у налаштуваннях редактора: Export → Android). Ключ для релізу передається змінними середовища:
`GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `GODOT_ANDROID_KEYSTORE_RELEASE_USER`, `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD`, потім
`godot --headless --path godot --export-release "Android" Afterfall.apk`.
