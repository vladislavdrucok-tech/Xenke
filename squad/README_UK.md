# Afterfall — Загін (прототип нового напрямку)

Окремий проєкт Godot 4.3. Старий платформер — у `../godot` (архів).

**Відкрити:** Godot → Import → `squad/project.godot` → F5.

**Керування:**
- На телефоні: палець у будь-якому вільному місці екрана — це плаваючий джойстик. Кнопки — «Імпульс», «Загін», дія біля об'єкта.
- На ПК: WASD або стрілки, пробіл — «Імпульс», E — дія.

Що зроблено, мої припущення й відмінності від референсу описано в `../docs/NEW_DIRECTION_UK.md`.

| Файл | Що робить |
|---|---|
| `scripts/main.gd` | ділянка біля Станції, цикл «ворог → ресурси → дія → зміна», завдання, збереження, автопрохід (`-- --demo=<папка>`), самотест (`-- --selftest`) |
| `scripts/unit.gd`, `hero.gd`, `enemy.gd` | рух по площині, загін слідом за лідеркою, автоатака з перевіркою видимості, вороги (виявлення, замах, удар, повернення в зону), анімації |
| `scripts/hud.gd` | інтерфейс: загін, ресурси, завдання, джойстик, бульбашки вимог, кнопка дії, смуги здоров'я, екран загону |
| `scripts/spr.gd` | піксельні спрайти з пакета у світі: кадри персонажів (точка ніг), стани предметів, тінь |
| `scripts/models.gd` | допоміжна геометрія (тіні-овали, паркан, жетони ресурсів) |
| `tools/prepare_assets.py` | бере атласи й предмети з пакета (`art/rest`, `godot/assets`), малює текстури землі → `assets/`, `data/sprites.json` |
