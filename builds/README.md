# Android builds for installing on the phone (download from GitHub: open the file, then "Download raw")

- `DeepBounce-1.1.0.apk` — Deep Bounce 1.1.0, підписаний релізний APK (ставиться поверх 1.0–1.0.3 зі збереженням прогресу; arm64-v8a + x86_64). Встановлення: `deep_bounce/README.md`.
- `DeepBounce-1.1.0.aab` — той самий реліз у форматі Android App Bundle, підписаний тим самим ключем: для завантаження в Google Play Console (Internal testing → Production). Налаштування товарів і реклами: `deep_bounce/docs/MONETIZATION_UA.md`.

Обидві збірки використовують **тестові** рекламні блоки Google (поки в `deep_bounce/config/monetization.cfg` не вписано реальні ID AdMob).
