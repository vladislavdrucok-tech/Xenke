## Частина 2. Для ChatGPT: про гру і правила

### Гра
**Afterfall: «Останній сад»** — 2D-гра з видом збоку для телефона й ПК, збирається в рушії **Godot**.

- **Світ:** 40 років після Падіння. Руїни, зарослі міста, забруднені землі, мутовані істоти.
- **Герої:**
  - штучний дослідник у подобі Альберта Ейнштейна;
  - Міра — 22-річна механікиня з поселення «Станція».
- **Мета:** лагодити техніку, рятувати насіння, відновлювати природу.

### Стиль (обов'язково)
- **Піксель-арт:** детальний, як на прикріплених концептах (рівень Terraria / Owlboy).
  - Чіткі піксельні краї, без розмиття й м'яких градієнтів «аерографа».
  - Темний теплий контур навколо предметів і персонажів.
  - Світло зверху ліворуч.
- **Палітра:** потертий метал, іржа, дерево, камінь, мох, ліани.
  - Тепле жовто-помаранчеве світло ламп.
  - Холодне блакитно-бірюзове освітлення підземель.
  - Неон тільки для кристалів, грибів і екранів.
- **Ракурс:** вид **строго збоку**, як у 2D-платформері. Не 3/4, не ізометрія, не перспектива згори.

### Технічні правила (кожна картинка)
1. **Фон — прозорий.** Якщо прозорість не виходить, суцільний **#FF00FF** (без відтінків).
   - Виняток — далекі шари фону (розділ C): вони непрозорі.
2. **Ніякого тексту, цифр, підписів, водяних знаків, рамок, ліній сітки** (крім тих, що вказані в завданні).
3. **Рівна сітка:** усі клітинки одного розміру, одна річ у клітинці по центру. Відступ від країв не менше 5%, сусідні речі не торкаються.
4. **Однаковий масштаб у межах аркуша.**
   - Людина заввишки ≈ 70% висоти своєї клітинки персонажа.
   - Двері — трохи вищі за людину.
   - Верстак — по пояс.
   - Ящик — по коліно.
5. **Стани одного предмета** (зламаний / полагоджений, закрита / відкрита) малюй **в однаковому розмірі й на тому самому місці** клітинки, низ предмета на одній лінії. Змінюються лише деталі.
6. **Напрямок:** персонажі й вороги дивляться **праворуч**, якщо не сказано інакше.
7. **Розмір картинки:** 1536×1024 (горизонтальна), 1024×1536 (вертикальна) або 1024×1024 (квадрат). Сітку беремо з завдання.

#### A5. Фони прологу (окремими шарами, для паралаксу)
У Godot шари рухаються з різною швидкістю, тому їх треба окремо.

- **Формат:** кожен шар **1536×1024**. Далекий і середній шари **безшовні по горизонталі**: лівий край продовжує правий.
- **Шари:**
  - `bg/<локація>_far.png` — найдальший план (небо, силуети руїн), **непрозорий**;
  - `bg/<локація>_mid.png` — будинки, естакада, стіни на середній відстані, **прозорий** там, де видно далекий шар;
  - `bg/<локація>_near.png` — передній план: ліани, уламки, труби, що звисають; **прозорий**, займає лише краї й низ.
- **Локації:** `bunker` (лабораторія під землею), `city` (зруйноване місто біля метро, захід сонця), `station` (поселення «Станція»: навіси, ліхтарі, теплиця вдалині).
- **Лінія землі:** у середньому шарі на рівні ~75% висоти. Нижче гра малює плитки.
