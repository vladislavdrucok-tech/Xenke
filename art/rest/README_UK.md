# Afterfall - решта графіки

Цей набір містить 209 додаткових зображень. Разом із попередніми 13 остаточними зображеннями пробної версії це 222 ігрові зображення.

## Як знайти картинку

1. Відкрий один із чотирьох PDF-каталогів. Кожне зображення має ID A001-A209.
2. Під зображенням указано номер ZIP-архіву й точний шлях PNG.
3. Розпакуй відповідний архів. Архіви незалежні: для відкриття одного не потрібні решта.
4. Усі архіви можна розпакувати в одну спільну папку. Зображення мають унікальні назви.

`ALL_ASSETS_INDEX.csv` містить загальний список із номером архіву, PDF і сторінкою.
`assets_manifest.json` містить розміри, прозорість, призначення та SHA-256 кожного PNG.

## Якість і версії

- Байти PNG-оригіналів збережено без змін. Архівація не змінює роздільність або альфа-канал.
- PDF містить оптимізовані копії для перегляду. Для Godot використовуй PNG з ZIP.
- `early_concepts` - ранні ідеї гри, включно з альтернативними напрямками до остаточного Afterfall.
- `legacy_*` - попередні набори персонажів, істот, ресурсів та предметів. Перед імпортом узгодь їхній стиль із поточною версією.
- `archive_superseded` - відомі замінені варіанти. У каталозі та JSON указано новішу заміну.
- `story_concepts` - сюжетні арти й референси. Інтерфейс, освітлення та предмети на таких артах можуть бути частиною цілісної картинки.
- `chapter_*`, `laundry_mission`, `water_mission` - графіка відповідних локацій і місій.
- Аркуші поз є вихідною графікою. Потрібні нарізка, вирівнювання, налаштування станів, колізій і перевірка анімацій у Godot.
