# План продажу на 24 години

Мета — 1–2 стоматології в Києві, що заплатили передоплату за впровадження. Нижче план по годинах з командами з цього репозиторію.

Чесно про шанси: за добу закрити угоду реально, але не гарантовано. Розрахунок на воронку: **50 контактів → 10–15 відповідей → 4–6 дзвінків → 1–2 угоди**. Це орієнтир, а не обіцянка. Що не закриється сьогодні, часто закривається за 2–5 днів, якщо ви не зникаєте.

## Година 0–1. Підготовка

```bash
cd dental-bot && npm install
cp config.example.json config.json   # ваше ім'я, телефон, Telegram, ціна, кількість місць
export ANTHROPIC_API_KEY=sk-ant-...
npm test && npm run sample           # переконайтесь, що все працює
cloudflared tunnel --url http://localhost:8787   # публічна адреса для посилань
```

Сервер потім запускайте з `PUBLIC_URL=https://….trycloudflare.com npm start`. Демо створюйте з тим самим `PUBLIC_URL`, щоб посилання в консолі й презентації були правильні.

## Година 1–3. Список клінік (`prospects.csv`)

Google Maps → «стоматологія» → райони Києва по черзі.

Кого брати:
- приватні клініки на 2–6 крісел;
- рейтинг 4.3+, від 40 до 500 відгуків;
- **є сайт із цінами** (без цін демо слабше);
- активний Instagram.

Кого не брати: мережі з колл-центром, клініки без сайту.

**Пріоритет:** відгуки на кшталт «не додзвонишся», «не відповіли в Instagram», «довго чекала відповіді». Цитату запишіть у колонку `pain_quote`. Це найсильніший аргумент, і він не ваш, а їхніх пацієнтів.

Заповніть щонайменше `name`, `website`, `phone`, `instagram`. Достатньо 40–60 рядків.

## Година 2–4 (паралельно). Таємний покупець

Увечері (19:00–22:00) напишіть 20–30 клінікам у той канал, який вони самі пропонують (Instagram, Telegram, Viber, форма на сайті). Питання має бути звичайне, справжнє:

> Добрий вечір! Скільки у вас коштує імплантація під ключ і чи можна прийти на консультацію в суботу?

- Час відправки запишіть у `mystery_sent_at`, час відповіді — у `mystery_answered_at`, канал — у `mystery_channel`.
- Не записуйтесь на прийом і не займайте чужий час: тільки одне питання.
- Ці дані потім внесіть у кабінеті («Налаштування» клініки → «Таємний покупець»). Тоді перший слайд презентації покаже фактичний час відповіді клініки, без вигаданої статистики.

## Година 3–6. Демо

```bash
node scripts/batch-demos.mjs sales/prospects.csv --max 20
```

Для кожного демо (5 хвилин на клініку):
1. Відкрийте посилання й поставте 5 питань:
   - ціна імпланта;
   - субота;
   - «болить зуб увечері»;
   - щось, чого немає на сайті;
   - запис з іменем і телефоном.
2. Якщо назва визначилась криво, виправте її в кабінеті.
3. Якщо бот обійшов мало сторінок або не знайшов цін, клініку відкладіть.

## Година 6–8. Відео (найкраще працює)

Для 10 найкращих клінік запишіть 40–60 секунд з екрана (Loom або телефон). Сценарій — у [`outreach.md`](outreach.md#відео-на-60-секунд). Найсильніший момент: ви залишаєте в чаті телефон, і **в ту ж секунду** в Telegram приходить заявка.

## Наступний ранок, 9:00–12:00. Контакт із власником

- **Дзвінок у клініку → вихід на власника чи головного лікаря** працює краще за повідомлення. Скрипт — в [`outreach.md`](outreach.md#дзвінок-у-клініку).
- Паралельно надішліть повідомлення з відео й посиланням на демо в Instagram, Telegram або на пошту власника.
- Через 3–4 години без відповіді — короткий фоллоу-ап.

## 12:00–18:00. Дзвінки й зустрічі по 15 хвилин

Хід розмови:
1. Презентація `…/pitch/<slug>`: 5 слайдів.
2. Живе демо: хай власник сам напише боту.
3. Ціна, гарантія, наступний крок.

Скрипт і відповіді на заперечення — в [`outreach.md`](outreach.md#зустріч-15-хвилин).

## Закриття

1. Надішліть [`offer.md`](offer.md) (оферта) і рахунок на 50%.
2. Після передоплати — запуск за 48 годин:
   - перевірте відповіді на 15 типових питань разом з адміністратором;
   - підключіть Telegram адміністратора (`/id`);
   - передайте один рядок коду для сайту;
   - якщо клініка хоче, запустіть Telegram-бота для пацієнтів.
3. Через тиждень надішліть клініці звіт: скільки діалогів, які теми, скільки заявок (кабінет → «Про що питають», «Заявки»).

## Чого не робити

- Не обіцяйте «+30% пацієнтів»: таких даних немає. Обіцяйте те, що можна перевірити: відповідь за секунди 24/7, заявки в Telegram, жодне повідомлення не загубиться.
- Не вигадуйте відгуків чи кейсів. Перший клієнт — це і є кейс. Можна запропонувати знижку за дозвіл назвати клініку.
- Не розсилайте шаблон сотням клінік: персональне демо працює саме тому, що воно персональне.
