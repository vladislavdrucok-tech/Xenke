Зразок композиції, масштабу й деталізації — концепт власника `art/concepts-iso/station_yard_concept.png`.

Зараз пробний двір (`iso/`) зібраний **тимчасово з самого концепту**:
- фон очищено від намальованого інтерфейсу й людей;
- об'єкти, за якими можна пройти, вирізано окремо;
- стани очисника й грядки зроблено перефарбуванням;

Щоб двір став справжньою грою, потрібні окремі PNG нижче.

## Частина 2. Правила (для ChatGPT)

### Ракурс — один для всього
- **Ізометрія 2:1** (як у концепті): камера зверху під кутом.
- Видно дах, верхні поверхні предметів і **дві бокові стіни** будівель.
- Лінії підлоги йдуть під кутом ~26,5° (на 2 пікселі вбік — 1 піксель угору).
- **Світло** зверху ліворуч, тепле вечірнє; лампи й вікна теплі, вода блакитна.

### Стиль
- **Деталізований піксель-арт**, як у концепті:
  - темний теплий контур, іржа, дерево, мох;
  - синя техніка, теплі ліхтарі.
- **Персонажі компактні:** приблизно **3 голови** заввишки, виразні силуети.

### Технічні правила
1. **Прозорий фон.** Якщо не виходить — суцільний **#FF00FF**.
2. **Без** тексту, цифр, літер, рамок, сітки й тіні на землі. Тінь гра малює сама.
3. **Масштаб:** людина, що стоїть, ≈ **118 px** заввишки (як у концепті 1536×1024); двері ≈ 150 px; ящик ≈ 45 px.
4. **Стани одного предмета** — у **однаковому розмірі й на тому самому місці** клітинки. Змінюються лише деталі.
5. **Точка опори** — середина основи предмета (для персонажа — між ступнями). Вона має бути на тій самій висоті в кожному кадрі й стані.
6. **Сітки кадрів** — рівні клітинки, одна поза в клітинці, по центру.

## Частина 4. Чек-лист перед відправкою
- [ ] Ракурс 2:1, як у концепті, в **усіх** картинках; видно дах і дві стіни.
- [ ] Людина ≈ 118 px, ~3 голови заввишки; масштаб предметів відповідає людині.
- [ ] Стани однакового розміру й на тому самому місці; ноги та основа — на тій самій точці.
- [ ] Дахи будівель — окремими файлами.
- [ ] Прозорий фон, без тексту, тіні на землі й сітки.
- [ ] Персонажі однакові в усіх кадрах і схожі на концепт.

### Фрази для виправлення
| Що не так | Фраза |
|---|---|
| Інший ракурс | `Redo it in the same 2:1 isometric angle as the attached concept: roof and two side walls visible.` |
| Не той масштаб | `Redo it at the same scale as the concept: a standing person is about 118 px tall.` |
| Стани зсунуті | `Redo it: all states the same size and position, the base at the same point.` |
| Персонаж змінився | `Redo it: the character must look exactly like in the concept and previous sheets.` |
| Є тінь/текст/сітка | `Redo it without ground shadow, text or grid lines, transparent background.` |
