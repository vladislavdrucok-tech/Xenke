# LOT 13: Lucky Garage

Мобільна 2D-гра в піксельному стилі на Godot 4.3 (GDScript), вертикальний екран, Android. Українська та англійська мови.
Окремий проєкт: інші теки репозиторію (`godot/`, `iso/`, `squad/`, `dist/` …) не змінювались.

**Ідея:** у тебе $500 і старий гараж «Лот 13». Купуй закриті коробки на аукціонах, відкривай, ремонтуй знахідки,
продавай із торгом, покращуй гараж і відкривай дорожчі аукціони. Гра нескінченна.

## Як відкрити
- Godot 4.3 → Import → `lot13/project.godot` → F5.
- На ПК мишка імітує дотик; Esc — «Назад».

## Технічно
- Екран 360×640 логічних пікселів, `canvas_items` + `expand`: працює на будь-якому вертикальному співвідношенні.
  Графіка — 2× піксель, фільтр Nearest; шрифт Pixelify Sans (OFL) з доданими «О» та «ʼ».
- Безпечні відступи під виріз камери та панель жестів на Android (`DisplayServer.get_display_safe_area`).
- Увесь інтерфейс будується кодом (`scripts/ui.gd` — фабрика кнопок/панелей, автозавантаження `UI`).
- Для слабких телефонів: GL Compatibility, `low_processor_mode`, `CPUParticles2D`, без `_process` у спокої,
  дрібні текстури (весь арт ≈ 200 КБ), звуки 22 кГц моно.
- Автозавантаження: `L` (тексти), `Game` (стан, економіка, збереження), `Sfx` (звук), `UI` (інтерфейс).

## Перевірки
- `python3 tools/check.py` — без Godot: синтаксис усіх скриптів (gdtoolkit), наявність усіх ресурсів, ключі перекладів
  в обох мовах і однакові `{заповнювачі}`, небезпечні для GDScript 4 конструкції.
- `godot --headless --fixed-fps 60 --path lot13 -- --selftest` — правила гри, дані, збереження, бот-економіка на 40 днів.
- `godot --headless --fixed-fps 60 --path lot13 -- --smoke` — проходить усі екрани й вікна як гравець
  (аукціон, відкривання, ремонт, торг, ломбард, події, покращення, «Назад»).
- `godot --rendering-driver opengl3 --resolution 360x640 --path lot13 -- --shots <тека>` — знімки 10 ключових екранів
  (у CI під Xvfb; `tools/shots_b64.py` / `tools/shots_decode.py` передають їх через лог завдання).
- `python3 tools/balance_sim.py 200 60` — симуляція економіки (темп відкриття аукціонів, гроші по днях).
- GitHub Actions `.github/workflows/lot13.yml`: імпорт → selftest → smoke → APK (артефакт `LOT13-Lucky-Garage-apk`)
  → знімки екранів (артефакт `lot13-screenshots`).

## Графіка та звук (генеруються, можна перегенерувати)
- `python3 tools/make_art.py [тека_прев'ю]` — усі PNG: предмети (`tools/art_items.py`), коробки, портрети, іконки,
  рамки інтерфейсу, гараж і його покращення, сцена аукціону, ефекти, іконка застосунку.
- `python3 tools/make_audio.py` — 25 звуків і 2 музичні петлі (чіптюн).
- `python3 tools/fix_font.py ../iso/assets/PixelifySans.ttf assets/fonts/pixelify_lot13.ttf` — шрифт.

## APK
Пресет «Android» (arm64-v8a + armeabi-v7a, без Gradle, портрет, вібрація). Підпис — `tools/debug.keystore`
(налагоджувальний ключ, пароль `android`; лише для тестових збірок, для Google Play потрібен власний ключ):
`godot --headless --path lot13 --export-debug Android /шлях/LOT13.apk`
(у редакторі: Editor Settings → Export → Android — шлях до SDK і цей keystore).
