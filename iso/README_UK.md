# Afterfall — двір «Станції» в ізометрії (2D)

Новий візуальний напрямок за концептом власника (`art/concepts-iso/station_yard_concept.png`).
Попередні прототипи лишаються без змін: `godot/` — платформер збоку, `squad/` — вид зверху в 3D.

**Відкрити:** Godot 4.3 → Import → `iso/project.godot`.

**Керування:**
- На телефоні: палець у лівій частині екрана — джойстик, кнопка «рука» — дія.
- На ПК: WASD або стрілки, E чи пробіл — дія.

**Що можна зробити в дворі:**
- склад: забрати й покласти ресурси;
- ящики біля майстерні: розібрати на брухт;
- верстат: створити ремкомплект;
- водоочисник: оглянути, полагодити, після чого він виробляє воду;
- чаша: набрати воду;
- Павло в теплиці: дає насіння;
- грядка: посадити → полити → паростки → капуста → зібрати;
- укриття: відпочити й зберегтися.

Прогрес зберігається в `user://iso_save.json`.

**Перевірка:**
- `-- --demo=<папка>` — автопрохід зі скриншотами;
- `-- --selftest` — 7 перевірок: разове списання, ланцюжок, збереження, колізія.

| Файл | Що робить |
|---|---|
| `scripts/yard.gd` | шари двору, сортування глибини за лінією основи, колізії за основою (полігони), прозорість того, що закриває героя, взаємодії, завдання, збереження |
| `scripts/actor.gd` | персонаж: точка між ступнями, крок, робота, дзеркалення |
| `scripts/hud.gd` | портрет із серцями, ресурси, завдання, джойстик, кнопка-рука з назвою дії, бульбашки над об'єктами, діалог, панелі |
| `tools/build_yard.py` | **тимчасово** ріже двір із концепту: фон, об'єкти, стани, персонажі, полігони → `assets/yard`, `data/yard.json` |
