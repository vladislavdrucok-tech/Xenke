# Afterfall — пробна сцена в Godot 4.3

Майстерня Міри на Станції: верстак → ремонтний вузол → ремонт фільтра → кран → чиста вода.
Мета — порівняти Godot з нинішньою браузерною версією (`dist/`). Графіка та сама: атласи героїв, Міри, реквізит, майстерня.

## Як відкрити
1. Завантаж Godot 4.3 (стандартний, не .NET): https://godotengine.org/download/archive/4.3-stable/
2. Godot → «Import» → вибери файл `godot/project.godot` → «Import & Edit».
3. F5 — запуск. Керування: A/D або ←/→, пробіл — стрибок, E — дія. Мишею можна натискати екранні кнопки.

## Що де
| Файл | Що робить |
|---|---|
| `main.tscn` | Сцена: фон, навіс, верстак, радіо, фільтр, ємності, Міра, герой, світло, камера. Предмети можна пересувати мишею в редакторі. |
| `scripts/actor.gd` | Персонаж із атласу поз: точка опори між чобітьми, однаковий масштаб кадрів, предмет у руці |
| `scripts/player.gd` | Рух, стрибок, вибір цілі в зоні, «одне натискання — одна дія», підхід на робоче місце, поштовхи ключем |
| `scripts/interactable.gd` | Предмет для взаємодії: зона (CollisionShape2D), назва, дія, причина відмови, золоті дужки |
| `scripts/filter_machine.gd` | Фільтр: 3 стани, маховик, манометр, лампа (PointLight2D), струмінь (CPUParticles2D), іскри |
| `scripts/state.gd` | Інвентар, рецепт ремонтного вузла, поточна мета |
| `scripts/main.gd` | Інтерфейс (мета, репліки, підказка, сенсорні кнопки, крафт), Міра, камера, автопроходження |
| `tools/export_assets.py`, `tools/export_station_art.cjs` | Переносять графіку з `dist/` у проєкт |
| `tools/fix_font.py` | Додає в шрифт Pixelify Sans великі «П» та «І», яких у ньому немає |

## Автоперевірка (без редактора)
`godot --path godot --rendering-driver opengl3 -- --demo=<папка>` проходить сцену сам, зберігає скриншоти й друкує час кадрів; з `--perf` — лише заміри.
