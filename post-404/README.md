# TIME POST: Посилки з майбутнього (Parcels From Tomorrow)

Робоча назва була «ПОШТА 404 / POST 404»; відділення в сюжеті й далі має номер 404.

Мобільна 2D-гра (портрет) на **Godot 4.7.2**, GDScript. Casual / puzzle / simulation / mystery.
Окремий проєкт у папці `post-404/` — інші проєкти репозиторію (Afterfall тощо) не змінювались.

## Як запустити

**На телефоні (Android):** `builds/TimePost-0.2.0-debug.apk` — відкрити файл на GitHub → «Download raw» → встановити
(дозволити встановлення з невідомих джерел). Це debug-підпис; для Google Play потрібен ваш власний ключ (див. нижче).

**На ПК:** Godot 4.7.2 → Import → `post-404/project.godot` → F5. Мишка працює як палець, стрілки клавіатури — як свайпи, Esc — пауза.

## Як грати
На конвеєрі приїжджають посилки. Порівняй рік на етикетці з табло **СЬОГОДНІ** (2038):
- **свайп ліворуч** — минуле (рік менший);
- **свайп праворуч** — майбутнє (рік більший);
- **свайп угору** — теперішнє (рік збігається, з 2-го рівня);
- **свайп униз** — карантин для небезпечних артефактів (з 7-го рівня).

Внизу є великі кнопки напрямків (вимикаються в налаштуваннях). Нові механіки відкриваються поступово й щоразу
пояснюються БІТом (гра стає на паузу). Генератор перевіряє кожну посилку: відповідь завжди можна вивести з того,
що видно, — вгадувати не потрібно.

Режими: **зміна** (75 с + покращення, надійність-«серця»), **спокійна зміна** (без таймера й штрафів),
**рекорд** (3 життя, таймер на кожну посилку), **щоденна аномалія** (60 с, особливе правило дня, уламки часу раз на добу).

## Що є в грі
- 10 типів відправлень: звичайні, пошкоджені етикетки, небезпечні артефакти, термінові, загадкові (підказка про епоху),
  серії, посилки від персонажів, парадокси (виправлений рік), колекційні золоті, теперішнє.
- Події: золота година, зсув календаря (змінює «сьогодні»), дзеркало (портали міняються місцями), кіт Квант, часова буря.
- 24 покупки: техніка (підйомник, прес, годинник, жолоби, УФ-сканер, віконце, ремонт БІТа), кімнати (архів, кімната
  відпочинку + кавоварка з офлайн-доходом, антена, лабораторія), декор, рідкісне обладнання за уламки, 5 маршрутів,
  хроноконвертер. Усе впливає на гру.
- Сюжет: пролог + 8 глав, вибори з наслідками (змінні «надія», «довіра», «пам'ять»), листи від персонажів,
  місто за вікном змінюється, 3 кінцівки (одна таємна). Після фіналу гра триває.
- Колекція з 26 предметів, рівні до 60, автозбереження з резервною копією, українська й англійська мови.

## Перевірки
```

xvfb-run godot --path post-404 --resolution 720x1280 -- --save=user://tour.json --shots=/tmp/shots   # скриншоти всіх екранів
```
Деталі: `docs/TESTING.md`.

## Збірка APK
Пресет «Android» у `export_presets.cfg` (без Gradle, arm64-v8a + armeabi-v7a, портрет, immersive).
Потрібні: шаблони експорту Godot 4.7.2, Java 17+, Android SDK з `platform-tools` і `build-tools/<версія>/apksigner`
(шлях — Editor Settings → Export → Android).
```
godot --headless --path post-404 --export-debug "Android" build/post404-debug.apk
```
Релізний підпис — через змінні середовища `GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `..._USER`, `..._PASSWORD`
і `--export-release`. Ключі, паролі й keystore у репозиторій не додаються (`.gitignore`).

**iOS:** пресет «iOS» підготовлено; збірка можлива лише на macOS з Xcode і обліковим записом Apple Developer
(Team ID, provisioning profile).

## Структура
| Шлях | Що |
|---|---|
| `scripts/core/rules.gd` | правила сортування, перевірка «чесності» посилки |
| `scripts/core/package_generator.gd` | генератор посилок на правилах |
| `scripts/core/shift_session.gd` | ігровий цикл зміни (без графіки, тестується headless) |
| `scripts/core/events.gd` | випадкові події |
| `scripts/core/economy.gd`, `upgrades.gd`, `progression.gd` | економіка, покупки, рівні й відкриття механік |
| `scripts/core/story.gd`, `story_data.gd`, `content.gd` | сюжет, персонажі, загадки, колекція, маршрути |
| `scripts/core/save_system.gd` | збереження з версіями, атомарним записом і резервною копією |
| `scripts/autoload/` | `Game` (профіль, налаштування, навігація, пауза у фоні), `Audio`, `I18n` |
| `scripts/ui/` | екрани: меню, зміна, результати, відділення, колекція, листи/глави, налаштування, сюжет |
| `tools/make_art.py`, `tools/make_audio.py` | генератори всієї графіки й звуку (оригінальні, без сторонніх ресурсів) |
| `tests/` | логічні тести та скриншот-тур |

Шрифт: Pixelify Sans (SIL OFL 1.1, `assets/fonts/OFL.txt`). Решта ресурсів створена для цієї гри.
