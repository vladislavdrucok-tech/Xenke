# Afterfall — стани грядки S2c…S2f (завдання для ChatGPT)

Грядка з капустою перед водоочисником у дворі «Станції» проходить у грі шлях:
**суха → посіяно → полито → паростки → капуста** (капуста вже є на `S1_yard_clean.png`).

Потрібні 4 картинки — по одній на кожен стан.

---

## Для тебе: як працювати

1. Відкрий **той самий чат**, де робились S1–S3. Якщо чату вже немає — новий чат, і прикріпи цей файл.
2. До **кожного** завдання прикріплюй:
   - `S1_yard_clean.png` — саме його, **не концепт** і не попередній результат;
   - `S2_bed_location.png` — показує червоним, яку грядку міняти.
3. Скопіюй промпт завдання, отримай картинку, перевір за чек-листом унизу.
4. Збережи з назвою як у завданні й надішли мені. Можна по одній.

---

## Правила (для ChatGPT)

- Це **редагування** `S1_yard_clean.png`, а не новий малюнок. Розмір **1536×1024**, той самий ракурс, стиль, світло.
- Змінюється **тільки земля й рослини всередині дерев'яної рамки** грядки, обведеної червоним на `S2_bed_location.png`. Це грядка з капустою перед водоочисником, ліворуч від кам'яної чаші.
- **Дерев'яна рамка грядки** — дошки й кутові стовпчики — лишається такою самою: та сама форма, місце й колір.
- Решту двору не чіпати. Гра вирізає лише ділянку грядки, тому дрібні зміни деінде не страшні, але грядка має стояти рівно на тому самому місці.
- Земля в усіх станах — у межах рамки, на тій самій висоті. Без людей, тексту, рамок, сітки.
