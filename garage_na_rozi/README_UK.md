# «Гараж на розі» 1.0.0

Офлайн-гра українською мовою для Android (Godot 4.5.1, GDScript, рендер GL Compatibility).
Гравець лагодить мопеди, мотоцикли й старий автомобіль у маленькому гаражі, купує стійку та підйомник,
проходить фінальне замовлення на сімейному універсалі, отримує емальовану вивіску й далі працює у вільній грі.

## Встановлення на телефон

1. Скопіюйте `garage-na-rozi-1.0.0.apk` на телефон (у репозиторії він лежить у `builds/`).
2. Відкрийте файл і дозвольте встановлення з цього джерела, якщо Android попросить.
3. Гра не потребує мережі: у застосунку немає дозволу на інтернет, усі малюнки, звуки й шрифти вже всередині.
   Єдиний дозвіл — вібрація (вмикається й вимикається в налаштуваннях гри).

Ідентифікатор пакета: `ua.garazhnarozi.game`, версія 1.0.0 (versionCode 1), Android 7.0+ (minSdk 24, targetSdk 35),
архітектури arm64-v8a, armeabi-v7a, x86_64. Прогрес зберігається в `user://garage_save.json` (з резервною копією `.bak`).

## Як грати

- Гра відкривається в гаражі. «Почати» — і перший клієнт прикочує зелений мопед.
- Торкніться частини транспорту з картки замовлення: відкриється крупний план.
- Кожен ремонт має три кроки: **огляд** (знайдіть причину; справна деталь показує ✓), **ремонт** (один жест) і **перевірка**.
- Відлік часу стартує з першого дотику на крупному плані. Вклалися в ціль — +30 чайових, далі вони зменшуються до нуля
  при подвійному цільовому часі. Оплата 100 гарантована за будь-який успішний ремонт.
- Пауза, підказка, згортання чи блокування телефона зупиняють відлік; після повернення натисніть «Продовжити».
- Кар’єра: 2 ремонти мопеда → стійка (200) → ще 2 мопеди → 4 мотоцикли (на стіні з’являється світлина) →
  підйомник (400) → 4 роботи з авто → фінал із трьох робіт на універсалі → вивіска, титри, «Відкрити майстерню».
- Вільна гра: черга клієнтів чергує транспорт і не повторює одну поломку двічі поспіль; на «Дошці робіт» можна взяти
  будь-яку відому поломку й покращити свій рекорд; у «Покращеннях» — лампа з емальованим плафоном, шафа для інструментів
  і новий колір воріт.

## Повторна збірка APK

Потрібно: Godot 4.5.1 (стабільний, офіційний), шаблони експорту 4.5.1, JDK 17–21, Android SDK
(`platform-tools`, `build-tools;35.0.1`, `platforms;android-35`).

1. Шаблони експорту: розпакуйте `Godot_v4.5.1-stable_export_templates.tpz` у
   `~/.local/share/godot/export_templates/4.5.1.stable/`.
2. У налаштуваннях редактора (Editor Settings → Export → Android) вкажіть `Android SDK Path` і `Java SDK Path`.
3. Ключ релізу **не входить у проєкт**. Тримайте `garage-na-rozi-release.jks` і пароль у приватному сховищі.
   Передайте їх Godot через змінні середовища (пароль не потрапляє у файли проєкту):

   ```bash
   export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=/шлях/до/garage-na-rozi-release.jks
   export GODOT_ANDROID_KEYSTORE_RELEASE_USER=garage-na-rozi
   read -rs GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD; export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD
   ```

4. Збірка й перевірка підпису (з теки `garage_na_rozi`):

   ```bash
   mkdir -p build
   godot --headless --path . --export-release "Android" build/garage-na-rozi-1.0.0.apk
   apksigner verify --verbose build/garage-na-rozi-1.0.0.apk
   ```

   Для оновлень у тому ж пакеті збільшуйте `version/code` в `export_presets.cfg` і підписуйте тим самим ключем.
   Відбиток сертифіката (SHA-256): `C9:1C:B3:58:72:82:7A:1B:D5:39:60:85:B6:35:04:A1:9E:4B:E6:81:8D:AD:E7:E0:26:66:BD:2C:4C:92:91:64`.

## Перевірки

Автотест керує справжньою грою дотиками (InputEventScreenTouch/Drag), ніяких «чітів» у логіці ремонтів:

```bash
godot --headless --path . --import
godot --headless --path . --fixed-fps 60 -- --save=user://test_save.json --selftest
# окремі частини: --only=repairs | career | slow | interrupt | queue
```

- `repairs` — кожен із 15 ремонтів (12 + 3 фінальні) проходиться жестами, базова оплата 100;
- `career` — уся кар’єра з чистого профілю через інтерфейс: замовлення, купівля стійки й підйомника дотиком по місцю
  на підлозі (подвійний дотик по «Купити» списує гроші один раз), фінал, титри, одне замовлення у вільній грі;
- `slow` — та сама кар’єра без чайових (кожна перевірка після подвійного цільового часу): баланс у кінці 900;
- `interrupt` — пауза, підказка, згортання (збереження активного часу), «Продовжити», перезапуск посеред ремонту й
  посеред фіналу, після оплати й після купівлі; подвійна виплата неможлива; довгий ремонт дає 100 без чайових;
  вивіска, гроші й рекорди зберігаються після перезапуску;
- `queue` — черга вільної гри чергує транспорт і не повторює поломку.

Знімки екрана (потрібен рендер, наприклад `xvfb-run`):
`godot --path . --rendering-method gl_compatibility --resolution 720x1280 --fixed-fps 60 -- --save=user://shot.json --shots=<тека> --what=start|garage|repairs`.

## Що перевірено у версії 1.0.0

- Автотест (Godot 4.5.1, headless, `--fixed-fps 60`): **137 перевірок пройдено, 0 провалів** — усі 15 ремонтів жестами,
  кар’єра з чайовими й без них (баланс 900, усі чайові 0, стійка й підйомник куплені), фінал, титри, замовлення у вільній
  грі, пауза/підказка/згортання/«Продовжити», перезапуски посеред ремонту, посеред фіналу, після оплати й після купівлі.
  Окремо всі ремонти проходять, коли телефон передає лише кожен третій дотик (`--sparse`).
- Підпис: `apksigner verify --verbose` — Verifies, схеми v2 і v3, один підписант.
- Емулятор Android 9 (API 28, x86_64, 1080×2220, програмний рендер ANGLE/SwiftShader, без KVM), режим польоту:
  встановлення саме цього APK, запуск без мережі, титульний екран, прибуття клієнта, дотик по фарі мопеда,
  діагностика й фіксація роз’єму, згортання кнопкою «Додому» → «Ремонт на паузі / Продовжити», примусова зупинка й
  повторний запуск посеред перевірки (крок і стан деталі відновились), виплата 100 + 25 чайових, примусова зупинка
  після виплати (баланс 125 зберігся, повторної виплати немає). Текст читається на екрані 1080×2220.
- На старому програмному GLES-транслятора емулятора (`-gpu swiftshader_indirect`) рушій не малює 2D: там ліміт
  261 uniform-вектор у фрагментному шейдері. Це обмеження емулятора, не телефонів; з `-gpu swangle_indirect` гра працює.

## Будова

| Файл | Що робить |
|---|---|
| `data/orders.json` | замовлення як дані: репліки, ціль часу, діагностика/ремонт/перевірка, підказки кроків, ціни, клієнти, сюжет |
| `scripts/game.gd` | стан гри, атомарне збереження (тимчасовий файл + перейменування, `.bak`), гроші, кар’єра, фінал, черга |
| `scripts/main.gd` | перебіг гри: клієнти, наближення до деталі, оплата, фінал, пауза, згортання, відновлення |
| `scripts/repair_base.gd` | спільна основа ремонту: кроки, відлік, ознаки, підказки, ярлики «працює / причина» |
| `scripts/gest.gd` | спільні жести: дотик із запасом, ковзання зі «клацом», поворот, ворушіння, ведення вздовж лінії |
| `scripts/repairs/r_*.gd` | 12 крупних планів (фара й двірник та панель також для універсала) |
| `scripts/garage_view.gd`, `art.gd`, `paint.gd` | ізометрична діорама, транспорт, люди; гуашеві заливки, мазки, м’які тіні, світло лампи |
| `shaders/gouache.gdshader` | повноекранний гуашевий прохід: нерівні краї, пігмент на межах, зерно паперу, теплий вінʼєт |
| `scripts/hud.gd` | український інтерфейс: монети, ціль, картки, бульбашки, меню, налаштування, дошка робіт, титри |
| `scripts/sfx.gd`, `tools/make_sfx.py` | звуки й музика (синтезовані офлайн, WAV у `assets/sfx`), вібрація |
| `tools/make_icon.gd` | іконка застосунку тим самим стилем |
| `scripts/selftest.gd` | автотести й знімки екрана |
