# LAST DEAL: Shop Simulator — журнал розробки

Окремий проєкт Godot 4.3 у папці `last_deal_mobile/`. Afterfall та інші папки репозиторію не змінюються.

## Стан (оновлюється після кожного етапу)

| Етап | Стан |
|---|---|
| 1. Основа: структура, сцена, UI, дані предметів і клієнтів | ✅ готово |
| 2. Механіки: торг, перевірка, склад, перепродаж, гроші, попит | ✅ готово |
| 3. Розвиток: дні, статистика, оренда, 3 покращення, збереження | ✅ готово |
| 4. Оформлення: піксель-арт, анімації, звуки, мобільна адаптація | ✅ базово готово |
| 5. Тестування: автотести, UI-прохід, Android APK | ✅ APK збирається; на реальному телефоні НЕ перевірено |

## Що зроблено
- **Ядро** (`scripts/core/`, без залежності від UI):
  `item_db.gd` (15 товарів, 21 дефект, стани), `customer_db.gd` (5 характерів із економічними параметрами),
  `market.gd` (попит: блукання з поверненням до середнього + події «хайп/обвал»),
  `negotiation.gd` (торг: межа ціни, терпіння, зустрічні пропозиції, образа),
  `customer_generator.gd`, `inventory.gd`, `economy.gd` (константи, оренда, покращення),
  `game_session.gd` (усі дії гравця, день, оренда, банкрутство, серіалізація), `save_system.gd` (атомарний запис JSON).
- **UI** (`scripts/ui/`): `main.gd` (безпечні відступи, верхня панель, вкладки, модальні вікна, ефекти грошей),
  `shop_view.gd` (піксельна сцена, дощ, неон, анімації входу/виходу клієнта), `shop_page.gd`, `inventory_page.gd`,
  `upgrades_page.gd` (покращення + статистика + графік), `modal.gd`, `ui_kit.gd` (тема, кнопки ≥ 88 px).
- **Автозавантаження**: `Game` (сесія, налаштування, автозбереження наприкінці кадру та при паузі застосунку), `Sfx` (синтезовані звуки).
- **Графіка**: уся оригінальна, генерується `tools/gen_art.py` (фон 180×170, 12 клієнтів, 15 предметів, іконки, іконка застосунку).
- **Шрифти**: Exo 2 (текст), Tiny5 (піксельні цифри/заголовки), DejaVu (символи) — усі під вільними ліцензіями.

## Баланс (за симуляцією ботом, 40 сидів × 30 днів)
- Старт 500 кр, оренда 30 + 4/день (стеля 200), 6 клієнтів/день (+2 з вивіскою), роздрібна націнка ринку ×1.2.
- «Розумний» бот (огляд + торг до 86% оцінки): банкрутство 1/40, медіана балансу день 10 ≈ 710, день 30 ≈ 1300 (після купівлі покращень).
- Випадковий бот (купує навмання): банкрутує 40/40 — рішення гравця мають значення.

## Результати перевірок (останній прогін)
- `tests/test_core.gd`: 3152 перевірки, 0 помилок (торг, баланс ніколи не мінус після покупки, подвійні дії,
  переповнений склад, попит, дні/оренда, покращення, збереження JSON і файл, пошкоджене збереження, банкрутство, симуляція ботами).
- `tests/ui_smoke.gd` (720×1280): 10 днів через кнопки UI → день 11, баланс 3757 кр, 60 куплено / 60 продано, 0 помилок;
  подвійне натискання «Купити»/продаж не змінює баланс двічі; банкрутство → «Почати нову гру» працює.
  Також перевірено скриншотами 540×1200 (20:9) і 900×1200 (планшет 3:4).
- `tests/restart_check.gd`: збереження → новий процес → стан ідентичний (включно з клієнтом посеред торгу).
- APK: підпис v2 підтверджено незалежним `apksigtool` («v2 verified»); дозвіл VIBRATE, орієнтація portrait.
- Лог запуску/виходу гри без помилок і попереджень.

## Як перевіряти
```sh
cd last_deal_mobile
godot --headless --path . --import                      # перший раз
godot --headless --path . -s res://tests/test_core.gd -- --ld-test   # ~3150 перевірок економіки й станів
godot --headless --path . -s res://tests/restart_check.gd -- --step=1 && godot --headless --path . -s res://tests/restart_check.gd -- --step=2
tools/run_ui_test.sh 12 /tmp/shots                         # UI-прохід 12 днів через кнопки + скриншоти (xvfb)
tools/build_android.sh build/LastDeal.apk                  # підписаний APK
```

## Відомі обмеження / ризики
- APK підписується власним `tools/android/apksigner` (схема v2) — Android SDK у середовищі недоступний (dl.google.com заблоковано).
  Перевірено лише власним верифікатором; на фізичному телефоні встановлення ще не перевірялось.
  Підпис v2 працює на Android 7.0+; на Android 5–6 (потрібен v1) не встановиться.
- Тестовий ключ `tools/keys/ld-test.p12` (пароль `lastdeal-test`) — лише для тестових збірок, не для Google Play.

## Важливі рішення
- Логіка гри повністю в `GameSession` (без UI) → тестується headless; UI лише викликає методи й перемальовується.
- Захист від експлойтів: кожна дія перевіряє стан (клієнт відкритий, предмет на складі, гроші ≥ ціни);
  пропозиція обмежена балансом; UI блокує кнопки на час анімацій; клієнт посеред торгу зберігається (перезапуск не «перекидає» клієнта).
- Ринок платить ×1.2 від «скупної» вартості (роздрібна націнка) — інакше маржа була замала і бот банкрутував.
- Купівля неонової вивіски додає 2 клієнти вже в поточний день.
- Збереження в `user://last_deal_save.json` (атомарно через .tmp), налаштування — `user://last_deal_settings.json`.
- Тестовий режим `-- --ld-test`: гра не пише на диск.
